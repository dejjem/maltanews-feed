About

This feed carries the daily Malta news digest produced by an automated pipeline (draft → validate → publish) running three times daily. Each digest is reviewed against strict date-integrity rules: only stories published today, Malta-related, non-sports, and non-opinion are retained. Duplicate coverage of the same event is merged into a single item with all contributing publications listed.

The feed keeps a rolling window of the most recent 50 items. It is generated fresh on every publish and committed to the repository that backs this page.

Validation

The feed passes the W3C Feed Validator. To check it yourself, paste the feed URL into validator.w3.org/feed.
